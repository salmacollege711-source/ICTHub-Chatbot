# ICTHub AI Chatbot

An AI-powered chatbot for ICTHub built with Python, Gradio, TF-IDF retrieval, and the Kilo AI API.

## Features

- Interactive Gradio chatbot interface
- Retrieves relevant information from the ICTHub dataset
- Uses TF-IDF and cosine similarity
- Generates natural-language responses with an LLM
- Uses environment variables for API-key security

## Project Files

- `app.py` - Gradio interface
- `chatbot.py` - chatbot logic and retrieval
- `icthub_dataset.xlsx` - ICTHub knowledge dataset
- `requirements.txt` - dependencies
